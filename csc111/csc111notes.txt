### Linear Search & Binary Search

Linear Search
-------------
Base case: if value is found (success) or value isn't present (fail)
Base case (fail):
  start = end --> -1

Base case (succeed):
  target = array[start] --> start

Recursive Case:
  search(start + 1, end)

Binary Search
-------------
Base case: if value is found (success) or value isn't present (fail)
Base case (fail):
  start = end --> -1

Base case (succeed):
  target = array[mid] --> mid

Recursive Case: lower half
  if target < array[mid]:
    search(start, mid)

Recursive Case: higher half
  if target > array[mid]:
    search(mid+1, end)

public void swap(int[] array, i, j) {
    int t = array[i];
    array[i] = array[j];
    array[j] = t;
}

public boolean isSorted(int[] array) {

## Postfix calculator

- iterate over input (arrays of string, operands, operators)
  - if an element is a number: push it onto the Stack
  - if an element is an operator:
    - pop two numbers of the stack
    - evaluate those two numbers based on the operator
    - push result back onto the stack
- top element of the stack is the result of the expression
  - if we encounter an empty stack
Infix: 2 + 2 (what we usually see)
Postfix: 2 2 +: easier for computers to parse
