## Random Numbers

- random numbers often aren't really random, they're pseudo random.
- start with a seed value and manipulate it to create a new value everytime
you generate numbers
-starting with the same seed always gives the same "random sequence
(int)(Math.random() * 6) + 1;

The function "Math.random()" generates a double from 0.0 (inclusive) to 1.0 (exclusive).
To generate random int values, you scale, truncate, and offset this number:

- Scale by multiplying by the number of possible outcomes you want. If we want ten
  different outcomes, then we write "(int)Math.random() * 10"
- Truncate by casting to an int: "(int)(Math.random() * 10)", remember parenthesis for
  the correct order of operations
- Offset by adding a number. If we want 1 to 10 instead of 0 to 9, then we can add 1:
  "(int)(Math.random() * 10) + 1"

- Usually a bad idea to use '==' and '!=' with any ref type

## Program vs Function I/o

- input/output: information entering and leaving a system (a program, fucntion, etc).
- At a program level:
    - IO.readln reads user input and can also print output
    - IO.print and IO.println print output to the terminal
- At the function level: just lookingat information travelling between functions, not info
    entering and leaving the program.
    - A functions parameters define inputs required to call the function
    - A function's return value sends output to the caller (the code that called the function)
    - A fucntion's return type tells other code what type of output the fucntion produces
    - Wriitng funcitons that only use their parameters and return value for input lets them
      more easily communicate with other parts of your program
