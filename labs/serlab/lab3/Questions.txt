2. Which methods from the Animal class were optional to override in <yourAnimalType>'s class? Why?
-
The eat() and sleep() methods can be overriden since it doesn't have the abstraction modifier in the parent class.
The cat object will use the eat() method in the Animal class if there is no eat() method in the Cat class.
If both methods exist, then the Cat class method will be used because the object was instantiated by the Cat class.
Same goes for the sleep() method.
